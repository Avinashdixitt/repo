How Fuzzy C-Means Works

Step 1 — Initialize: Choose C cluster centers.

Step 2 — Calculate distance: Calculate the distance between each point and every cluster center.

Step 3 — Calculate membership: Unlike K-Means, a point does not belong completely to one cluster. Instead it has a membership value for every cluster.

For example:
Point P1: Cluster 1 = 0.80
Cluster 2 = 0.20

Step 4 — Calculate new centers: The cluster centers are calculated using the membership-weighted mean.

Step 5 — Repeat: Update memberships and cluster centers until the centers stop changing.
